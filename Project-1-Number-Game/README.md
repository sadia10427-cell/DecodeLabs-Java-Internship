# Number Guessing Game

A simple Java console-based Number Guessing Game developed as part of my DecodeLabs Java Programming Internship.

## Description

The program generates a random number and asks the user to guess it. After each guess, the program provides feedback to help the user determine whether the guessed number is too high or too low.

The game continues until the user guesses the correct number.

## Features

- Generates a random number
- Takes user input using `Scanner`
- Compares the user's guess with the generated number
- Provides hints for incorrect guesses
- Displays a message when the correct number is guessed

## Technologies Used

- Java
- Java `Scanner`
- Java `Random`

## How to Run

1. Make sure Java is installed on your computer.
2. Clone or download this repository.
3. Open the project in a Java-supported IDE such as VS Code, IntelliJ IDEA, or Eclipse.
4. Compile and run `NumberGame.java`.
5. Follow the instructions displayed in the console.
