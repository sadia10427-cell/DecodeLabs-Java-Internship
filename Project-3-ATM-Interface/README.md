# ATM Interface

A simple console-based ATM Interface developed in Java as part of my DecodeLabs Java Programming Internship.

## Description

This program simulates basic ATM operations through a console-based interface.

The program allows the user to:

- Display their current balance
- Deposit money
- Withdraw money
- Exit the ATM

The project uses two classes, `ATM` and `BankAccount`, to separate the ATM interface and banking operations.

## Features

- Display current balance
- Deposit money
- Withdraw money
- Prevent negative deposits
- Prevent negative withdrawals
- Prevent withdrawals greater than the available balance
- Validate menu selection
- Handle invalid user input
- Continue displaying the menu until the user chooses to exit
