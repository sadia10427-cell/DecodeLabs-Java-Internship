# Grade Calculator

A Java console-based Grade Calculator developed as part of my DecodeLabs Java Programming Internship.

## Description

This program takes the number of subjects and the marks obtained in each subject from the user. It calculates the total marks, obtained marks, average percentage, grade, and academic status.

The program also checks whether the entered marks are within the valid range of 0 to 100.

## Features

- Takes the number of subjects as input
- Takes marks for each subject
- Validates marks between 0 and 100
- Calculates total marks
- Calculates obtained marks
- Calculates average percentage
- Assigns a grade based on the percentage
- Displays Pass or Fail status

## Grading System

| Percentage | Grade |
|------------|-------|
| 90% or above | A |
| 80% – 89% | B |
| 70% – 79% | C |
| 60% – 69% | D |
| Below 60% | F |

## Technologies Used

- Java
- Java `Scanner`
- Conditional statements
- Loops

## How to Run

1. Make sure Java is installed on your computer.
2. Open the project in a Java-supported IDE.
3. Compile and run `GradeCalculator.java`.
4. Enter the number of subjects.
5. Enter the marks for each subject.
6. The program will display the calculated result.
